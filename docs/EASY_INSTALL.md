# RC.4 — Easy Install

## Сборка (только для сопровождающего)

На Windows x64 распаковать исходники и запустить BUILD_RELEASE.bat. Требуется Python 3 на машине сборки и интернет для первой загрузки зависимостей. Сборщик проверяет опубликованные SHA-256 Python и wheel lz4, сохраняет лицензии, запускает smoke test портативного Python и проверяет синтаксис PowerShell. Папка `DIRT_RU_RC4_dist_...` создаётся рядом с папкой исходников. Кеш рядом, не включать в Git.

В пользовательском ZIP нет сетевых запросов и требований к системному Python. Вложен официальный python.exe, собственного EXE нет. Запуск BAT вызывает Windows PowerShell с политикой только для текущего процесса. Не меняет глобальные настройки системы.

## QA

1. Проверить архив и сборку. Не публиковать до проверки прав и совместимости.
2. Полностью распаковать Windows ZIP в путь с пробелами и кириллицей. На ПК с установленной RC.1/2 запустить Install_RU.bat, выбрать игру: существующая установка должна быть распознана, кнопка «Уже установлен» недоступна; ярлык можно создать отдельной кнопкой.
3. Запустить ярлык, проверить русский текст и английскую озвучку, закрыть игру.
4. Uninstall_RU.bat — выбрать ту же папку. Проверить восстановление оригинальных хешей и удаление только соответствующего ярлыка.
5. Install_RU.bat — повторно установить на ванильную игру. Проверить запуск.
6. На чистой Windows без установленного Python выполнить аналогичный цикл. Проверить отказ для неправильной папки, запущенной игры, неподдерживаемого EXE, отсутствие резервной копии при удалении.

Ядро и версия формата backup остаются RC.1. Перед записью свежего патча wrapper дополнительно требует точного совпадения индекса и DAT-хвостов с подтверждённой RC.1. Журнал сохраняется в LocalAppData/DIRT_5_RU_MOD. Сохранения игры не изменяются. Резервная копия остаётся в `_ru_tools` после удаления. Ошибка создания ярлыка не откатывает успешную установку: о ней сообщается отдельно.

Ограничения: только проверенный бинарный профиль игры; поддержка других сборок не установлена. Поддержку Windows GUI и портативного runtime ещё необходимо подтвердить в реальной среде.

## Проверка состояния RC.4

При открытии и выборе папки выполняется read-only проверка EXE, индекса, размеров архивов, известных хвостов и резервной копии (если она существует). Полная проверка ресурсов для установленной версии. После установки или удаления состояние обновляется. Наличие резервной копии после удаления не означает установленный мод. Статус VANILLA не заменяет полную предварительную проверку при установке.
