# Publication

Use BUILD_RELEASE.bat to generate the RC.4 source and offline Windows archives. Upload only the contents of the source archive to the repository, and only the Windows ZIP and its checksum manifest to Releases. Do not commit the runtime cache, dist directories, game assets, logs, backups, or private handoff material. Keep release private until rights and compatibility review; mark RC as pre-release. See EASY_INSTALL.md and QA.md.
