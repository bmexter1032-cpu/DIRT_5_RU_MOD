# Font deltas

`font_deltas.zip` is generated by the maintainer from the installed and verified v10.1 and its local backup. It contains only resource-length XOR deltas plus a manifest of 32 original and patched SHA-256 hashes. It is not a ZIP of complete original game fonts or archive blocks. These deltas are game-derived material and need a distribution rights review. A source template missing this file cannot install.
