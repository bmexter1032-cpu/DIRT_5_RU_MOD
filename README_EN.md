# DIRT 5 — Russian Localization

Full Russian text localization for DIRT 5 on PC: 6,473 strings, Russian interface and subtitles, original English voices. Original languages are preserved.

[Download](https://github.com/bmexter1032-cpu/DIRT_5_RU_MOD/releases)

## Installation

1. Download and fully extract `DIRT_5_RU_MOD_1.0.0-rc.4_Windows.zip`.
2. Close the game and run `Install_RU.bat`.
3. Select the game folder and click Install («Установить»).

Start the game using the Russian version desktop shortcut. The installer checks compatibility automatically.

## Uninstallation

Close the game, run `Uninstall_RU.bat`, select the game folder and click Uninstall («Удалить»). Original files will be restored from backup.
