## Easy Install runtime

The Windows release includes unmodified official CPython 3.13.17 binaries (except the local `_pth` configuration) and the python-lz4 4.4.5 Windows x64 wheel. Original Python LICENSE.txt and wheel license/metadata files are retained in `_data/runtime/`. Download sources and SHA-256 pins are in `_data/RUNTIME_PROVENANCE.txt` and `tools/build_easy_release.py`.
